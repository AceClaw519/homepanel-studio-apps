# Changelog

## 1.0.2

- Add Picture widgets with a separate image library, HA image entities, framing controls and fullscreen viewing.
- Add the official cyan HomePanel Studio icon and logo to Home Assistant's app listing.
- Improve camera presets, motion defaults, overlay activity handling and editor selection/resizing.
- Refine manual editor tabs, grid appearance/history and shared surface controls.
- Preserve existing saved dashboards, v1 licensing and installation data.

## 1.0.1

- Updated widget system presets and saved-control compatibility corrections.
- Improved accessibility, Camera modal and tap behavior, Media controls, State dismissal and Weather forecast date agreement.
- Retains major-v1 data, installation identity, key-only licensing and Supervisor-managed Home Assistant connection.
- Same-major update test release. No automatic saved-widget appearance migration.
- ARM64 (aarch64) image added October 29 from the same 1.0.1 application source for Raspberry Pi hardware testing. The existing amd64 image is unchanged. 32-bit ARM is not supported.

## 1.0.0-beta.8 — experimental beta

- Supervisor-managed installation with persistent data and prebuilt amd64 image.
- Automatic server-side Home Assistant connection and direct LAN Web UI.
- Cold backup policy, storage-major guard and one-time configuration-based login recovery.
- Existing key-only Pro activation; installation ID remains in Diagnostics.

Real HAOS install/update/backup restore and viewing-device acceptance remain pending.
