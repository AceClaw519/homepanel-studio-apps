# HomePanel Studio apps

Home Assistant OS installation repository for **HomePanel Studio v1**.

Experimental beta for amd64 and 64-bit ARM (aarch64). Both images pass isolated container acceptance; ARM64 is newly available for Raspberry Pi hardware testing, not a completed hardware/performance certification. 32-bit ARM is not supported. Back up your installation before updates.

Add this repository URL in Home Assistant's Apps store:

```text
https://github.com/AceClaw519/homepanel-studio-apps
```

Then install **HomePanel Studio v1**, start it and choose **Open Web UI**. See [installation, port configuration and recovery](homepanel_studio_v1/DOCS.md).

Only installer metadata and documentation live here. The application source repository remains private. Public availability of the application image does not grant Pro access; Pro requires a valid license. V1 purchases cover that purchased major version. A future paid major is a separate app/update stream and an explicit upgrade choice, not a silent v1 update.
